# OKICRAFT

a minecraft modpack for exploring, building, and automating together, with expanded terrain, farming, storage, and proximity voice chat.

[download 1.0.0-beta3](https://github.com/okisooo/OKICRAFT/releases/download/mrpack/OKICRAFT.1.0.0-beta3.mrpack) · [release notes](https://github.com/okisooo/OKICRAFT/releases/tag/mrpack)

## start playing

1. download `OKICRAFT.1.0.0-beta3.mrpack` from the link above.
2. use a launcher with `.mrpack` support. in prism launcher, choose `Add Instance` → `Import` and select the downloaded file. see the [launcher import guide](https://prismlauncher.org/wiki/help-pages/zip-import/).
3. let the launcher install the pack's dependencies, then launch the imported instance.

the published pack targets minecraft `1.20.1` and forge `47.4.10`. its version is `1.0.0-beta3`, so expect a beta experience.

## what's inside

- mechanical automation with `Create` and storage with `Applied Energistics 2`.
- new terrain, farming, building, and quality-of-life additions.
- proximity voice chat through `Simple Voice Chat`.

this repository holds the pack's shared configuration and server tooling. see the [feature overview](MODPACK_SUMMARY.md) and [server setup notes](SERVER_SETUP.md) for more context.
